# IDE 코드 비교와 선택 줄 AI 채팅

## 목표

전후 코드 비교 옆에서 특정 쪽의 줄을 선택하고, 선택 코드와 앞선 답변을 연결해 AI와 대화를 이어간다.
기존 읽기 전용 실행기·건별 승인·관찰 격리를 유지한다. 개인정보·기밀·도메인 자료는 가져오지 않는다.

## 완료 기준

- [x] 변경 전/후 쪽의 줄 클릭·Shift/드래그 선택과 코드 첨부 미리보기를 제공한다.
- [x] 우측 채팅에 사용자 질문·AI 답변·대기/실행 상태를 표시하고 같은 지문에서 후속 대화를 지원한다.
- [x] 대화 참조는 서버의 같은 방·파일·지문에서만 조립하며 한도·승인·관찰 격리를 검사한다.
- [x] 합성 브라우저·회귀 검증, 공개 위험 검토와 기존 작업 브랜치 push를 확인한다.

전달하면, UI를 채팅으로 바꿔도 권한은 확대되지 않을 것으로 예상한다. 실패 지점은 다른 파일·지문 이력
