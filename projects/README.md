# projects

`PROJECTS.md`가 프로젝트 식별자와 책임을 한두 줄로 보여주는 색인이라면, 이 폴더는 프로젝트별 상세 소개를
파일 하나씩 관리한다.

- 파일명: `projects/<project-id>.md`
- 자기 프로젝트 문서만 수정한다. 타 프로젝트 정정은 request로 전달한다.
- 프로젝트 간 계약과 전체 규칙은 `docs/`가 정본이며, 프로젝트 소개와 충돌하면 `docs/`를 따른다.
- 공개 저장소에 적합한 책임·접점·계약 포인터만 기록한다. 내부 경로·호스트·인증·운영 기밀은 공개 문서에
  넣지 않고 필요한 경우 ignored local overlay에서 관리한다.

권장 내용:

- 개요와 책임
- 소유 도메인과 주요 기능
- 제공·소비 계약
- 다른 프로젝트와의 접점
- 소스 오브 트루스 문서
- 현재 알려진 제약과 관련 request·task
